# Runway

A personal course tracker for Waterloo. It pulls deadlines from LEARN, course websites, Piazza emails, and pasted outlines into one calendar with prep time and reminders. It keeps lecture notes, and for courses that allow AI, adds a cleaned copy and answers questions about them with links back to the source.
